## How to run

1. Clone the repository: `git clone https://github.com/<your-username>/<repo-name>.git`
2. Open `index.html` in a browser (an internet connection is needed for the jQuery CDN and the demo images).
3. Open DevTools → Console to see the message `jQuery is ready!`.

## Publishing on GitHub Pages

Repository → **Settings** → **Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → **Save**.

## Technologies
